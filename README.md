# tedtedted/homebrew-tap

Homebrew formulae for [jazzclub](https://github.com/tedtedted/jazzclub), a console client for
Pandora internet radio.

```sh
brew install tedtedted/tap/jazzclub
```

`brew upgrade` keeps it up to date. The formula supports Apple Silicon Macs.

`Formula/jazzclub.rb` is written by jazzclub's release workflow on every release, from a template in
the jazzclub repository
([packaging/homebrew/jazzclub.rb.in](https://github.com/tedtedted/jazzclub/blob/main/packaging/homebrew/jazzclub.rb.in)).
Changes made here are overwritten; open issues and pull requests against
[jazzclub](https://github.com/tedtedted/jazzclub) instead.
